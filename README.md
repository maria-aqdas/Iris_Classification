# 🌸 Iris Flower Classification 🌺

An end-to-end Machine Learning project developed for **CodeAlpha Task 1** to classify Iris flower species based on their morphological measurements. 🌿✨

---

## 📌 Project Overview 🎯

The **Iris Flower Classification** project is a classic supervised machine learning problem. The goal is to accurately identify and classify Iris flowers into one of three species (*Iris setosa*, *Iris versicolor*, and *Iris virginica*) using physical petal and sepal attributes.

### 🌟 Key Objectives:
* 🧹 **Data Exploration & Cleaning:** Inspect the dataset for null values, shapes, and distributions.
* 📊 **Exploratory Data Analysis (EDA):** Visualize feature relationships using pair plots, histograms, and scatter plots.
* ⚙️ **Data Preprocessing:** Encode species labels and split data into training and validation sets.
* 🤖 **Model Building & Evaluation:** Train classification models and assess performance using accuracy scores and confusion matrices.

---


## 🌸 Dataset Features 📐

The dataset consists of measurements across four distinct botanical features:

* 🟢 **Sepal Length** (cm)
* 🟢 **Sepal Width** (cm)
* 🌸 **Petal Length** (cm)
* 🌸 **Petal Width** (cm)

**Target Classes:**

1. *Iris-setosa* 🌼
2. *Iris-versicolor* 🌸
3. *Iris-virginica* 🌺

## 🔄 Machine Learning Workflow ⚙️

1. **Data Ingestion & Understanding** 📥
* Load the Iris dataset and inspect summary statistics (`mean`, `std`, distributions).


2. **Exploratory Data Analysis (EDA)** 🔍
* Generate pair plots to observe clear species separation boundaries (notably Petal Length vs. Petal Width).
* Correlation heatmaps to detect strong feature dependencies.


3. **Model Training & Comparison** 🧠
* Train supervised classifiers (e.g., Logistic Regression, KNN, Decision Tree, Support Vector Machine).


4. **Model Evaluation** 🏆
* Evaluate predictions with:
* 🎯 **Accuracy Score**
* 🧩 **Confusion Matrix**
* 📋 **Classification Report** (Precision, Recall, F1-Score)
